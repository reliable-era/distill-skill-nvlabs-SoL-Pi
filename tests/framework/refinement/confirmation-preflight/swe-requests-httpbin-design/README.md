Use the authentic `postmanlabs/httpbin` implementation pinned in plan.json, with candidate publisher image `kennethreitz/httpbin`; source-to-image correspondence and immutable digest remain unverified. The original public Requests source requires both HTTP port 80 and HTTPS port 443. Its HTTPS check is an expected pass-to-pass test that failed in the isolated run. An HTTP-only service is insufficient.
