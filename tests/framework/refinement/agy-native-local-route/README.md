The [connection implementation](https://github.com/google-antigravity/antigravity-sdk-python/blob/12f9a4c3becf487302dc799b0f59054f01f3ddb9/google/antigravity/connections/local/local_connection.py) resolves google/antigravity/bin/localharness and communicates through a binary protocol; it does not launch the frozen agy CLI. Source calls that separate harness Go-based; native agy is only established as a stripped ELF. These are distinct harness identities and versions.
